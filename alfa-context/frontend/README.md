# Альфа Контекст — интерфейс прототипа

Статический фронт без зависимостей. Откройте dist/index.html либо запустите
`python -m http.server 8080 --directory dist`.

Реализованы лента, смена компании/роли, поиск, фильтры, сохранённые события,
карточка разбора, профиль, граф платежных связей и справочник источников.
Профили трёх компаний экспортированы ядром из предоставленных CSV.
Новости, оценки релевантности и интерпретации являются маркированными
учебными сценариями. Вызовов LLM и автоматического сбора новостей нет.
Сохранённое хранится в localStorage браузера.

Файлы: dist/index.html — структура; dist/style.css — адаптивные стили;
dist/app.js — взаимодействия; dist/data.js — срез профилей.
