# Альфа Контекст — интерфейс

HTML/CSS/JS без сборки и внешних зависимостей. Сервер backend раздаёт интерфейс
и API с одного адреса. Из папки `backend` запустите:

```powershell
python -m news_api
```

Откройте http://127.0.0.1:8080. Настройка моделей и сбор публикаций описаны
в корневом README. Открытие `dist/index.html` напрямую позволяет смотреть
локальный срез профилей и граф связей; для новостей и анализа нужен сервер.

Лента загружается через `/api/feed` для выбранных компании и роли. Кнопка
«Анализировать новости» сначала запускает сбор MOEX, ТАСС и Альфа-Банка с сохранением файлов
в `data/news/`, затем анализирует их через Gemma и GLM и обновляет результаты.
Интерфейс показывает этапы сбора и анализа; кнопка доступна и при пустой папке
новостей. При ошибке сбора отображается сообщение и можно повторить запуск.
В карточке доступны факты, влияние, ограничения, ссылка на публикацию
и уточняющий вопрос через `/api/questions`. При отсутствии подключения моделей
интерфейс показывает это явно. Демонстрационных новостей и ручных весов нет.
MOEX и ТАСС отбираются за 48 часов, пресс-релизы Альфа-Банка — за последнюю неделю,
до 200 на источник. Пресс-релизы — новости источника, а не загруженная экспертная
аналитика или официальные прогнозы банка. Экспертная позиция банка не генерируется,
`bank_view` остаётся `null`.

Сохранённые события хранятся в `localStorage` отдельно для каждой компании и роли.
При смене контекста старые запросы и ожидание анализа прекращаются в интерфейсе;
уже запущенная серверная задача может завершиться в фоне. Профиль и граф
платёжных связей сохраняют ограничения исходных CSV. `dist/data.js` содержит
резервный срез трёх реальных обезличенных профилей из этих данных.

Проверка интерфейса без запросов к моделям: из корня проекта запустите
`python -m http.server 8097 --bind 127.0.0.1 --directory frontend`, затем откройте
http://127.0.0.1:8097/tests/smoke.html. Стенд проверяет ленту, фоновые задачи,
смену компании/роли, сохранение, уточняющие вопросы и защиту вывода от HTML/URL
инъекций. Все обращения `/api/*` в изолированном стенде подменяются локально.
