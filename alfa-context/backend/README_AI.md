# Gemma → GLM → лента новостей

`google/gemma-4-26b-a4b-it` классифицирует новости по деловой тематике.
Только релевантные новости поступают в `z-ai/glm-5.3-flash`: анализ получает
профиль компании, платёжные связи, ограничения исходных данных и роль пользователя.
API отдаёт сохранённый результат фронту. Ключ используется только сервером.

## Запуск без Docker

Из `alfa-context`, в Python 3.12+:

```powershell
python -m pip install -r backend/requirements-api.txt
Copy-Item .env.example .env
```

Если `.env` уже существует, сохраните его. Вставьте ключ в `LLM_API_KEY`.
Адрес шлюза и точные ID двух моделей уже заданы. До добавления ключа сервер
запускается, показывает профили и сохранённую ленту; новые вызовы моделей отключены.
После изменения `.env` перезапустите сервер.

```powershell
Set-Location backend
python -m news_api
```

Открыть <http://127.0.0.1:8080>. Фронт и API обслуживаются одним сервером.
На экране ленты нажмите «Анализировать новости». Задание выполняется в фоне,
интерфейс получает его статус и загружает результат для выбранной компании/роли.

Свежие новости предварительно собирает существующий парсер. Из `alfa-context`:

```powershell
docker compose build parser
docker compose run --rm parser
```

Локальный сбор без Docker описан в [README_NEWS.md](README_NEWS.md).
Сервер не запускает сбор и платные вызовы автоматически при открытии страницы.

## Запуск через Docker

Из `alfa-context`, с `.env` рядом с `compose.yaml`:

```powershell
docker compose up --build api
```

Открыть <http://127.0.0.1:8080>. Новости и AI-хранилище подключены из `data/`.
После изменения ключа: `docker compose up --force-recreate api`.

## Профили компаний

По умолчанию доступны три настоящих профиля из текущего среза `frontend/dist/data.js`.
Для расчёта этих профилей по полной локальной базе импортируйте CSV, из `alfa-context`:

```powershell
python backend/core.py --db data/context.sqlite import data
```

Перезапустите сервер. При наличии `data/context.sqlite` профили читаются из неё.
Можно выбрать другие ID через переменную окружения `CONTEXT_COMPANY_IDS`
(например, `U_23929,U_12345`); для них предварительно нужна импортированная база.
Параметры сервера `--context-db`, `--ai-db`, `--news-dir` позволяют изменить пути.

## Контракты и сохранение данных

- Сырой контракт парсера не меняется: `news.json`, `moex.json`, `tass.json`.
- Новые непустые порции дополнительно сохраняются в `data/news/batches/` до
  замены текущей выдачи и состояния дедупликации. Старые порции, созданные до
  этой версии, можно принять только если они ещё находятся в `news.json`.
- `data/ai.sqlite` хранит принятые тексты, классификации и анализы отдельно от
  `state.json` парсера. Ошибка GLM не означает успешный анализ.
- В текущую ленту и новый анализ попадают новости за последние 48 часов;
  более старые исходные данные и кэши сохраняются в хранилище.
- Повторный запуск использует кэш успешных этапов; профиль компании, роль,
  тематика, текст, модель и версия промпта участвуют в выборе результата.
- Gemma возвращает JSON `relevant`, `confidence`, `category`, `reason`.
  При `relevant=false` вызов GLM пропускается.
- GLM возвращает `type` (`risk`, `opportunity`, `neutral`), `relevance` (0–100),
  `summary`, `connection`, `impact`, `action`, `facts`, `uncertainties`.
  Ответ проверяется по типам и границам перед сохранением.
- ID, заголовок, URL, источник и дата берутся из исходной статьи. Банковская
  позиция не генерируется: без загруженной аналитики `bank_view=null`.
- Вопрос в карточке отправляется GLM с сохранённой новостью, анализом и профилем;
  данные другой компании/роли не подмешиваются.

## Настройки и расходы

Основной адрес: `https://changellenge.up.railway.app/v1`.
Запасной адрес для российских хостингов: `https://api.alfahack-gateway26.ru/v1`.
Для переключения измените `LLM_BASE_URL` и перезапустите сервер. Автоматического
переключения после ошибки нет, чтобы не дублировать запросы.

`NEWS_AI_TOPIC` меняет тематику классификации; `NEWS_AI_BATCH_LIMIT` по умолчанию
ограничивает порцию десятью статьями. `LLM_MAX_CALLS_PER_RUN=20` ограничивает
вызовы в одном запуске, включая повторные HTTP-попытки; `LLM_RETRIES=1` и
`LLM_TIMEOUT=90` задают повторы и таймаут. `LLM_RUN_TIMEOUT=180` ограничивает
время одного запуска. Вопрос — отдельный запуск GLM.

Дневной бюджет **500 ₽ общий для команды**, его контролирует шлюз. Ограничение
числа вызовов не гарантирует денежный остаток. При `Budget has been exceeded`
запрос не повторяется; согласно инструкции организаторов, сброс — в 03:00 МСК.
Ключ не передаётся браузеру и не включается в образ Docker.

Шлюз использует OpenAI-compatible `POST /chat/completions` с Bearer-ключом;
ответ читается из `choices[0].message.content`. Формат протокола описан в
[справочнике Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create).

## HTTP API

| Запрос | Назначение |
| --- | --- |
| `GET /api/health` | Готовность подключения без ключа в ответе |
| `GET /api/companies` | Доступные профили компаний |
| `GET /api/feed?company_id=...&role=cfo` | Сохранённая персональная лента |
| `POST /api/analyze` | `{company_id, role, limit?}` → `202 {job_id}` |
| `GET /api/jobs/<job_id>` | `queued/running/completed/failed`, результат и ошибки |
| `POST /api/questions` | `{company_id, role, news_id, question}` → ответ и источники |

Роли: `cfo`, `ceo`, `treasury`. Сервер по умолчанию слушает только localhost.
Одновременно выполняется один анализ или вопрос; параллельный запрос получает 409.
Задания прогресса хранятся в памяти, результаты — в SQLite и переживают перезапуск.

## Проверка без ключа

Из `alfa-context/backend`, с установленными `pytest` и `requirements-api.txt`:

```powershell
python -X utf8 -m pytest -q tests/test_news_ai.py tests/test_news_api.py tests/test_news_e2e.py tests/test_core.py
```

Проверки подменяют ответы моделей и не тратят бюджет. Они проверяют порядок
Gemma→GLM, отсев, сохранение и повторы после ошибок, контекст компании/роли,
валидацию JSON, HTTP API и отсутствие утечки ключа. Реальный вызов шлюза
необходим после добавления ключа, чтобы подтвердить доступ команды к моделям.
